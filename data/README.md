# Các mẫu JSON

- `plants/*.json`: name, cost, hp, type và thông số hành vi tùy loại.
- `zombies/*.json`: name, hp, speed, damage, attack_rate, armor tùy chọn.
- `levels/*.json`: available_plants, waves, starting_sun.
- `config/game-settings.json`: cấu hình lưới và Linh Khí.

JSON phải là object. ID là tên file không gồm `.json`.
