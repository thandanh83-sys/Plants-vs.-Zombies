# Zombie sprites

Thêm sprite PNG thủ công theo đúng ID của file JSON trong `data/zombies/`.

Ví dụ: `data/zombies/cuong-thi-thuong.json` → `assets/zombies/cuong-thi-thuong.png`.

Kích thước khuyến nghị: ảnh PNG nền trong suốt, một cương thi trên mỗi ảnh, chủ thể nằm giữa khung. Nếu sprite chưa tồn tại, game tự vẽ hình dự phòng.
