# Plant sprites

Thêm sprite PNG thủ công theo đúng ID của file JSON trong `data/plants/`.

Ví dụ: `data/plants/truc-tien.json` → `assets/plants/truc-tien.png`.

Kích thước khuyến nghị: ảnh PNG nền trong suốt, một cây trên mỗi ảnh, chủ thể nằm giữa khung. Nếu sprite chưa tồn tại, game tự vẽ hình dự phòng.
