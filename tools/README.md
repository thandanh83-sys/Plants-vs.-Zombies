# Tools

`rename_assets.py` chuyển các ảnh UI nguồn ở root repo thành tên/path asset chuẩn.


## AI Content Studio

- Run python tools/game_ai_studio.py agents to list specialist agents.
- Run python tools/game_ai_studio.py inspect --kind plants to inspect current game data.
- Run python tools/game_ai_studio.py lint "..." to inspect a design prompt.
- Run python tools/game_ai_studio.py generate plants --id <id> --brief "..." to create a local validated draft. Drafts are not installed by default.
- See docs/AI_CONTENT_STUDIO.md for provider configuration and safety boundaries.
