## Quy cách

- PNG, nền trong suốt đối với cây/cương thi.
- Mỗi file chỉ chứa một nhân vật, căn giữa và chừa khoảng trống quanh viền.
- Dùng cùng một tỷ lệ khung hình cho các sprite cùng nhóm.
- Không đổi ID file nếu chưa cập nhật trường `sprite` trong JSON.
